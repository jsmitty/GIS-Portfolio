# GIS Portfolio

A collection of selected GIS, remote sensing, and web mapping projects demonstrating geospatial analysis, application development, and spatial communication.

## Featured Projects

### Landsat 8 Reflectance Comparison

An interactive Google Earth Engine application comparing Landsat 8 top-of-atmosphere (TOA) reflectance with surface reflectance imagery from summer 2016. The split-panel map highlights the subtle effects of atmospheric correction, while spectral-profile charts compare reflectance characteristics for water, vegetation, urban land, soil, and clouds.

**[Open the Live Google Earth Engine App](https://jeff-smith.users.earthengine.app/view/landsat-8-reflectance-comparison)**

### ArcGIS StoryMap Project

An interactive ArcGIS StoryMap created as a portfolio-ready web mapping project. It combines web maps and narrative content to present spatial information in an accessible, interactive format.

**[Open the ArcGIS StoryMap](https://storymaps.arcgis.com/stories/10fe7ea382954be18d9c6701db44b2e3)**
